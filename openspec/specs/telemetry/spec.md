# telemetry Specification

## Purpose

This capability is **retired**. QASpec collects no usage telemetry. The `src/telemetry/` module and all related configuration (`anonymousId`, `noticeSeen`, `OPENSPEC_TELEMETRY`, first-run notice) have been removed.

## Requirements

_No active requirements. All prior telemetry requirements were removed in the purge-openspec-legacy change._
